# Vela 0.3.3 文件工作区验收

验收日期为 2026-11-20，设备为 OPPO Find X9s Pro，Android 16。正式包名为 `com.dallovers.phoneagent`，versionCode 为 20。手机现有正式版已实测。

## 使用入口

从侧栏进入「文件 → 打开手机文件夹」，选择内部共享存储及目标目录后点「使用此文件夹」。选择存储根目录可以浏览系统允许的共享文件。首次使用时点「前往系统设置」，由用户开启所有文件访问权限。

真机检查发现正式版权限已经开启，已直接打开对应系统页面核实。用户随后要求继续使用现有 App，本次继续验证时使用现有正式版。

「询问此文件夹」会创建绑定当前目录的文件对话。模型可以按提问列目录、分段读取 UTF-8 文本。页面会展示读取范围，读取结果发往当前配置的模型接口。编辑文件可在文件页保存，回复可从菜单保存到对话目录。

## 实现内容

- 工作区支持真实手机目录绑定、子目录浏览、内部存储与可用外部卷识别。导入仍可创建副本，直接打开目录后的编辑会更新原件。
- 每次文件操作重新检查权限、存储卷及路径。限制目录穿越及符号链接，过滤 Android/data、Android/obb。
- UTF-8 文本单文件上限 1 MB，保留 BOM，写入使用临时文件和原子替换。保存时核对已读版本，原件变化后提示冲突。
- 文件夹对话提供 list_directory、read_text 两个工具，目录每页 40 项、文本每段最多 6000 字符，本轮最多 12 次工具读取。会话重启后保留绑定目录，历史会话兼容缺省字段。
- 文件引用支持子目录相对路径。其他格式可用「打开方式」交给已安装的查看器，通过单文件只读 URI 授权打开。

## 当前边界与未验证项

系统授权范围为共享存储，其他应用的私有数据、Android/data 等仍受安卓隔离限制。模型文件工具当前支持目录浏览与 UTF-8 文本读取，保存回复通过页面操作完成。PDF、图片、Word 等格式的模型解析能力需按附件功能单独核验。

目标正式包的 instrumentation 测试 APK 安装两次返回 -99，因此设备测试改为正式 App 页面操作及共享文件独立读回。不能将 assembleDebugAndroidTest 成功写成设备自动测试通过。二级存储卷、移除存储卷及其他应用查看器尚未逐项真机验证。
