# 0.1.10 本机服务开启引导修正

2026-11-19，versionCode 11。

问题：原“连接手机 → 前往系统设置”只打开无障碍总列表，未解释这是本机系统授权，更没有指明本应用服务。

修正：卡片改为“开启本机操作服务”；按钮改为“打开系统无障碍设置”；展示 OPPO 路径“已下载的应用 → 手机助手操作服务 → 开启 → 返回助手”。新会话入口也改为“查看指引，开启本机操作服务”。对无法打开系统页和权限限制显示手动导航说明。

本机验证：公开 ACTION_ACCESSIBILITY_SETTINGS 打开 OPPO 无障碍总页；点击已下载的应用后确有“手机助手操作服务”，服务详情页见 evidence/service-settings.png。直接详情 action 在本机要求系统权限 OPEN_ACCESSIBILITY_DETAILS_SETTINGS，不能作为普通应用可靠入口，因此未将它写入应用，也未申请系统权限或绕过限制。

最终 APK 已覆盖安装。构建 assembleDebug、testDebugUnitTest、lintDebug 成功；40 tests，0 failures；lint 0 errors，5 warnings。本轮未新增对应纯 UI 文案测试。未复验所有厂商手动入口和系统异常分支。

验证过程中 agent 只导航查看，没有切换服务开关。安装后手机出现服务已连接及 OPPO 的授权保留提示，该提示留给用户处理；不把这当作 agent 完成授权的证据。

来源：Android Settings 的公共无障碍入口文档 https://developer.android.com/reference/android/provider/Settings ，详情 action 的系统限制参考 AOSP Settings.java https://android.googlesource.com/platform/frameworks/base/+/refs/heads/android17-release/core/java/android/provider/Settings.java ，最终以本机实测为准。
