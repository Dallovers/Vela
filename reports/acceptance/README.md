## 证据位置

- `v0.1.7/evidence/`：可安全用于校内展示的本地练习截图和去敏记录。
- `v0.1.7/checks/`：单元测试 XML、lint 报告、构建日志、APK 元数据和 SHA-256 基线。
- `evidence/private/`：从设备直接取得的原始截图与日志，可能含个人聊天预览。不要展示、上传到公共仓库或复制到汇报 PPT。仅在必要时由项目维护者本机检查。
- `../builds/`：其他构建日志和诊断信息。
