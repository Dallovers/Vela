# Vela 0.3.8 验收报告

验收日期 2026-11-21。版本号 `0.3.8`，版本代码 `25`。APK 对应源码提交 `0187e69944717c209a162790e8ae97911b0d059c`。

## 本版改动

- 「手机操控 → 副屏试运行」支持在指定的虚拟副屏中输入两整数相加的算式。Vela 优先定位原生计算器按键，向该副屏派发点击，最后核对窗口内的算式和计算结果。支持的两个加数均为 1 至 999。
- scrcpy 在电脑端通过 USB 创建副屏。Vela 使用已开启的操作服务读屏和点击，断开副屏、切换计算器窗口或锁屏时会在执行检查处停止。该流程只向同一个已确认的副屏派发手势。
- 手机本地运行日志保留开始、动作回执和结果核对事件。另外补入已随 0.3.7 安装包交付的文档读取源码修订，使工作表与幻灯片按清单顺序读取，并保留完整的文档解读答复。

## 复现步骤

1. 连接 USB，在 Android 上授权 USB 调试并开启 Vela 操作服务。电脑下载安装 [scrcpy 5.0.1](https://github.com/Genymobile/scrcpy/releases/tag/v5.0.1)。
2. 在 scrcpy 解压目录运行以下命令，在屏幕编号独立的虚拟屏上打开 OPPO 计算器。

   ```powershell
   .\scrcpy.exe --new-display=720x1280/280 --start-app=com.coloros.calculator --no-audio
   ```

3. 在手机上打开 Vela，进入「手机操控 → 副屏试运行」，输入 `24+39` 并点「在副屏试算」。在运行期间可切到桌面或系统显示设置，通过电脑预览观察计算器，然后在 Vela 查看读回结果。
4. 再次开始试算，期间关闭电脑上的 scrcpy。回到 Vela 确认断开提示。

## 未验范围

当前入口是 USB 副屏原型，实际支持范围为上述 OPPO 计算器加法。常规模型任务、其他应用、手机独立创建副屏和无线运行尚未接入。主屏并行验收覆盖切换页面和一次滑动，连续手势、锁屏后恢复、不同虚拟屏尺寸及其他机型有待真机验证。本轮未重跑 0.3.7 文档读取的独立真机验收。
