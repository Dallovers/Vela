# 手机助手 0.2.2 独立验收报告

2026-11-19；versionCode 14；OPPO Find X9s Pro / Android 16。最终 APK 已覆盖安装。

APK：artifacts/apk/current/PhoneAgent-0.2.2-debug.apk。SHA-256：`0BD6D77BD761050A6746A61E16C562D66BCA4252743EB3CBC732C204AF9DC0CA`。

## 已实现

- 新对话选择“聊天 / 手机助手”，旧会话按原来的手机助手模式兼容。聊天发送纯文字和当前会话完整历史交换，不读取屏幕，不声明手机工具，不依赖操作服务；手机助手沿用 0.2.1 执行链。
- 聊天采用 SSE 流式正文，忽略 reasoning_content；停止取消网络请求，错误/断流/截断不算完成。只保留已完成的最近 16 轮及最多 60000 字符背景，排队中的未来要求与中断要求不进入当前请求。长历史之外的内容可能不再被模型记住。
- 回复提供复制/系统分享入口。对话选项提供 Markdown 导出、归档/移出归档；列表增加归档筛选。运行和待答会话不允许归档。
- 会话 schema 升到 3，兼容读取 1/2，未知版本拒绝写入；归档和模式一起持久化。旧版不支持 schema 3，不应直接降级覆盖。

## 实际验证

- 构建 `./build.ps1 -Tasks @('assembleDebug','testDebugUnitTest','lintDebug')` 成功；59 项 JVM 测试通过，0 失败；lint 0 errors / 10 UseKtx warnings。
- 候选包文字聊天实测发现 Android JSONObject 的 null content 被转为文字，已改为只接受 String 正文并增加含 null 的推理分片回归。修复后真机“Reply only Clean022.”返回 Clean022，未混入 null/思考正文。
- 系统文件选择器完成保存；读取本轮构造的导出文件核对共 85 字符，含用户测试请求和 Clean022；公开样例见 evidence/export-example.md。只导出可见消息，不导出配置、隐藏推理、截图或调试日志；可见消息本身仍可能含用户私人内容。
- 归档后检查手机会话中的 archived=true，输入发送禁用；最终包覆盖安装后仍保留归档和 CHAT 模式，移出归档写回 false。
- 最后一次重编译额外放开独立聊天被其他会话待答阻塞的入口，并使操作服务断开不取消正在进行的文字聊天。自动检查重跑通过、最终包已安装；服务断开期间持续流式聊天尚未故意关闭用户权限真机复测。
- 回复分享是系统 ACTION_SEND chooser 实现；没有发送给外部联系人，未把分享结果记为外部送达。微信/手机点击执行链本轮没有重测，也没有重复发微信。
