# 0.1.8 会话纵向实现

2026-11-18。基线：本地 Git 首次提交保留整理后的 0.1.7；只本地提交，不推送。

## 第一阶段范围与页面

旧版把 UI、日志和执行历史集中在单任务 Controller，没有持久会话或可答复的问题。现在以会话列表/新建、步骤编辑、运行状态、上下文编辑和待答区域组织主页面；模型、调试、记录继续独立。练习页提供确定性歧义注入和自由文本答复。

## 数据与恢复

`TaskSession` 保存稳定 ID、标题、目标、约束、用户摘要、更新时间、步骤列表、状态和待答问题；步骤具有 ID、完成条件、状态、模型结果。问题携带 ID 和 taskId，答复校验 sessionId/questionId，只接受一次。用户答复追加到本会话用户摘要；模型结果保存在任务结果中。共享摘要最长 6000 字符，单次答复最长 1000 字符；模型只接收本会话摘要、当前任务、最近结果、有限历史和最新观察。未把 key 或截图写入会话文件。

采用应用私有目录内版本化 JSON（schema=1）与 Android AtomicFile，避免增加数据库依赖；当前只有初始 schema，未知版本拒绝加载并禁止覆盖，未来需明确迁移。数据损坏保留原文件。RUNNING 载入后变为 PAUSED，待答问题保留；不恢复旧模型请求、屏幕编号或动作。新任务/恢复均截图。当前同步小文件写入适合演示规模，后续需移至 IO dispatcher 或 Room。

## 决策与并发约束

`AgentDecision` 为 Act、AskUser、Complete；DeepSeek 仍用单个 phone_action function，其他服务仍用 JSON。本地拒绝混合决策、多对象、空完成结果及无效动作。Controller 是唯一设备操作入口，所有运行共享一个 Job 和 generation；取消后协程检查取消状态，执行器入口也检查，旧结果不能继续分发。已派给系统的手势可能自行完成。待答期间其他操作入口被阻止。答复清除问题后重新启动循环、重拍屏幕，绝不执行旧决策。跨进程不承诺外部效果 exactly-once：若系统动作执行后未保存结果就崩溃，必须依赖新屏幕复核，真实外部动作尚未验收。

## 询问与通知

本轮完成模型 ask_user 与练习歧义注入；目标复核冲突仍主要拒绝/有限重试，尚没有完整的本地风险分类与候选冲突自动提问策略。因此不宣称模型在所有危险动作前一定询问。通知使用 POST_NOTIFICATIONS、通用文案及返回会话 PendingIntent；用户在调试页主动请求权限，未授权不阻塞持久问题。通知点击和 Android 13 的行为未真机验收。
